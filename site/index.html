Diagnostic · do not headline

Whole IDE
bytes.

Production ide.js plus workers. Lil language hosts are tiny; TypeScript is the same Microsoft ts.worker on both pages. The CSS and worker gaps are not a complete style/worker rewrite. Compression this far apart is a warning, not a trophy.

Not 100% feature parity. The Lil editor is a LilScript runtime plus a monaco-editor-core catalog, not monaco-editor with a few files swapped. Official tsc is unchanged. Context-menu items and several contrib surfaces still differ. Use the submodule table above if you want a size argument that can survive scrutiny.
